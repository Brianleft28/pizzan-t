## 🛠️ Proposed Changes

### Global Configuration Layer (`~/.gemini/config/GEMINI.md`)

Se inyectarán permanentemente las siguientes reglas al archivo raíz de configuración del sistema:

1.  **Cross-Language Integration (*Language Parsing*)**: 
    Se habilita el uso híbrido de español base, con inyección de términos técnicos de ingeniería de software en Inglés (*Tech Words*) y conceptos culturales/educativos en Japonés.
2.  **Strict Table Formatting (Formato Bebita)**:
    Se programa un *Trigger* (Disparador) que reacciona a las frases "bebita, como seria" o "damelo en table". Esto fuerza a la IA a estructurar el *Output* (Salida) con un saludo específico, encabezados, tabla comparativa, conclusión y siguientes pasos.
3.  **Japanese Transcription Standard (Furigana & Romaji)**:
    Todo output en japonés pasará por un filtro de formato estricto: `[Kanji/Vocabulario] (Furigana - Romaji)`. Esto asegura la correcta lectura (読み方 - Yomikata) para un usuario auDHD aprendiendo el idioma.
